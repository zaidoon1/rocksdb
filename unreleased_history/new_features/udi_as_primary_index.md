Added experimental `BlockBasedTableOptions::use_udi_as_primary_index`. When enabled together with `user_defined_index_factory`, all block-based-table reads automatically route through the UDI; the standard index is still built (for rollback and SST-format compatibility) but is not consulted on reads. Companion option `fail_if_no_udi_on_open` controls whether opening an SST that lacks a UDI block is an error. Both options remain experimental and subject to change.
